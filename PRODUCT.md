# Product

## Register

product

## Users

LunoRX developers and designers use the gallery to evaluate and compose the site's shared UI. Public developers and designers use it as a practical reference for available components and their expected behavior.

## Product Purpose

Provide one reliable catalog of the shadcn/Base UI and Magic UI components available to LunoRX, with examples that can be tried in the browser and reused in real pages. Success means users can find a component, understand its intended behavior, and start from working code without guessing about project styling or dependencies.

## Brand Personality

Quiet, precise, tool-like. The interface should feel dependable and clear while remaining approachable to people browsing the public catalog.

## Anti-references

- No noisy component dumps without useful grouping or search.
- No inaccessible controls, dead demos, or examples that require hidden state to work.
- No pure-black surfaces, gradient-heavy styling, or decorative animation that competes with the component being demonstrated.

## Design Principles

- Show the component in context and make its behavior easy to try.
- Keep the component and its example code discoverable together.
- Use the LunoRX zinc palette and squircle radius vocabulary consistently.
- Load interactive behavior only where the user needs it.
- Keep keyboard access, readable contrast, and reduced motion as default requirements.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Every interactive example must work with a keyboard, have visible focus and accessible names, and respect reduced-motion preferences. Do not rely on color alone to communicate state.
